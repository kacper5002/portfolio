# Skill icons

Static SVG assets served locally. No runtime package or external CDN.

- Devicon: https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6 (MIT; see LICENSE-devicon).
- Simple Icons: https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c (CC0; see LICENSE-simple-icons.md). Timescale.
- sql.svg: original generic database pictogram.
- zabbix.svg: original red tile with a white Z, matching the supplied mockup.
